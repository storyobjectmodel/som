# Contributors

The Story Object Model was developed through the **IBC 2026 Accelerator project
SMART STORIES**, and published at IBC 2026 in Amsterdam.

SOM exists because people from competing organisations agreed to describe a story the
same way. That is the hard part of an interoperability standard, and it is worth
recording who did it.

## How to be listed

Contributions to the standard include schema design, worked examples, the glossary,
review that changed a decision, vendor integration work that proved a family, and
demo participation that exercised the model under real conditions.

If you contributed and are not listed, open a pull request adding yourself — that is
the intended route, and it does not need anyone's permission.
